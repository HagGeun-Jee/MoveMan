# 주방짐 중심 이사 자재 산출 시뮬레이션 및 구현 명세서 (24평형 아파트 기준)

## 1. 개요 및 목적
- **작성 일시**: 2026-10-24
- **목적**: 
  - 이사 현장의 실제 특성인 **"주방 짐의 80~90%는 플라스틱 바구니(운반 바구니)로 포장된다"**는 점을 반영하여, 견적 작성 시 입력된 공간별 CBM과 물품 정보로부터 **필요 이사 자재(바구니, 단프라 박스, 보호재, 소모품 등)를 자동 산출하는 알고리즘 및 시뮬레이션 모델**을 정립한다.
  - 향후 웹 및 모바일 앱의 견적 작성 화면, 차량 인수인계서, 자재 재고관리 시스템 연동 코딩 시 공식 기준 자료로 활용한다.

## 2. 현장 포장 방식의 핵심 분석 (왜 주방은 바구니인가?)

| 공간 / 품목군 | 현장 포장 및 운반 방식 | 주 소요 자재 | 비고 |
|---|---|---|---|
| **주방 식기 / 유리류** | 깨지기 쉬운 도자기·유리그릇은 에어캡(뾱뾱이) 완충 포장 후 충격에 강하고 눌리지 않는 단단한 플라스틱 바구니에 담음 | **청색 이사 바구니 + 에어캡** | 종이/단프라 박스는 찌그러짐 위험으로 부적합 |
| **냉장고 / 김치냉장고** | 냉기 보존 및 국물/물기 누수 방지를 위해 위생 비닐을 속포장으로 씌운 바구니에 수납 | **청색 이사 바구니 + 위생 비닐** | 냉동식품은 아이스팩 동봉 |
| **냄비·조리도구·양념** | 형태가 불규칙하고 무거워 바구니에 테트리스식으로 적재 | **청색 이사 바구니** | |
| **의류·침구 (침실/안방)** | 부피가 크고 가벼우므로 대형 박스에 밀봉 포장 | **단프라 박스 (대)** | 정장/코트는 행거박스 사용 |
| **도서·서류 (서재)** | 무게가 무거우므로 터짐 방지를 위해 중형 박스에 분할 적재 | **단프라 박스 (중)** | |

## 3. 24평형 아파트 공간별 짐 분석 및 자재 시뮬레이션
- **대상 평형**: 24평형 아파트 (전용 59㎡, 방3 / 욕실2 / 거실 / 주방 / 베란다 / 팬트리)
- **가구 구성**: 3~4인 가족 (일반적인 5톤 탑차 1대 분량, 약 20~25 CBM)

### (1) 주방 & 냉장고 구역 (바구니 집중 구역)
- **싱크대 상/하부장 식기 및 조리도구**:
  - 밥그릇, 국그릇, 접시, 유리컵: 완충 포장 후 바구니 **7 ~ 8개**
  - 냄비, 프라이팬, 믹서기, 밀폐용기: 바구니 **4 ~ 5개**
  - 수저세트, 조리도구, 양념통, 소형잡화: 바구니 **3개**
- **냉장고 + 김치냉장고**:
  - 양문형 냉장고(800L) 냉장실/냉동실 반찬 및 식재료: 바구니 **5 ~ 6개**
  - 김치냉장고 김치통 및 장류: 바구니 **2 ~ 3개**
- **건식품 / 키친타올 / 일회용품**: 가벼운 마른 짐용 단프라 박스(중) **2 ~ 3개**
- **소계**: **이사 바구니 22 ~ 24개**, **단프라 박스(중) 2 ~ 3개**, **에어캡 1롤**, **비닐봉투 15장**

### (2) 침실 & 안방 구역 (의류·침구 박스 중심)
- **장농 / 붙박이장 / 서랍장 의류**:
  - 접는 옷, 티셔츠, 바지, 속옷: 단프라 박스(대) **10 ~ 12개**
  - 이불, 베개, 담요류: 단프라 박스(대) **5 ~ 6개**
  - 정장, 코트, 롱패딩, 원피스: 옷걸이 박스(행거용) **3 ~ 5개**
- **침대**:
  - 퀸/킹(Q/K) 매트리스 및 슈퍼싱글 매트리스: 매트리스 전용 방수커버 **1 ~ 2개**
- **소계**: **단프라 박스(대) 15 ~ 18개**, **행거 박스 3 ~ 5개**, **매트리스 커버 1 ~ 2개**

### (3) 거실 / 서재 / 욕실 / 현관 구역
- **서재 / 공부방**:
  - 책장 도서, 전집, 서류: 단프라 박스(중) **6 ~ 8개**
- **거실 & 베란다**:
  - 거실 장식품, 소품, 멀티탭, 쿠션, 베란다 잡화: 단프라 박스(대/중) **4 ~ 5개**
- **욕실 (화장실 2곳)**:
  - 수건, 세면도구, 샴푸/바디워시, 드라이기: 이사 바구니 **3 ~ 4개**
- **현관 & 신발장**:
  - 신발류 및 현관 잡화: 이사 바구니 또는 전용 신발박스 **4 ~ 5개**
- **소계**: **단프라 박스 10 ~ 13개**, **이사 바구니 7 ~ 9개**

## 5. CBM 데이터 기반 자재 자동 산출 알고리즘 공식

견적서 작성 화면(`EstimateForm`)에서 입력된 공간별 품목 데이터를 바탕으로 자재 소요량을 자동 계산하는 공식:

```typescript
/**
 * 견적 입력 데이터로부터 필요 자재 수량을 자동 계산하는 알고리즘
 */
function calculateRequiredMaterials(items: EstimateItem[], environment: any) {
  // 1. 공간별 / 품목별 CBM 집계
  const kitchenCbm = getCbmByLocation(items, ['주방', '팬트리']);
  const fridgeInnerCbm = getInnerCbmByName(items, ['냉장고', '김치냉장고']);
  const closetInnerCbm = getInnerCbmByName(items, ['장농', '서랍장', '옷장']);
  const bookcaseInnerCbm = getInnerCbmByName(items, ['책장', '책상']);
  const bedCount = getItemCountByName(items, ['침대']);

  // 2. 바구니 수량 계산 (주방 짐 85% + 냉장고 + 욕실/신발장 기본 할당)
  // 바구니 1개당 체적 약 0.08 ~ 0.10 CBM
  const kitchenBaskets = Math.ceil((kitchenCbm + fridgeInnerCbm) / 0.10);
  const bathroomBaskets = 3; // 욕실 기본
  const shoeBaskets = 4;     // 신발장 기본
  const totalBaskets = Math.max(10, kitchenBaskets + bathroomBaskets + shoeBaskets);

  // 3. 단프라 박스(대) 계산 (의류, 이불 등 침실 수납짐)
  // 단프라 대형 1개당 체적 약 0.15 ~ 0.18 CBM
  const clothesBoxes = Math.ceil(closetInnerCbm / 0.15);
  const totalDanpraLarge = Math.max(8, clothesBoxes);

  // 4. 단프라 박스(중) 계산 (도서, 서류, 주방 건식품)
  // 단프라 중형 1개당 체적 약 0.10 CBM
  const bookBoxes = Math.ceil(bookcaseInnerCbm / 0.10);
  const totalDanpraMedium = Math.max(5, bookBoxes + 3);

  // 5. 옷걸이(행거) 박스 계산
  const hangerBoxes = Math.min(6, Math.max(2, Math.ceil(closetInnerCbm * 0.4)));

  // 6. 소모성 자재 계산
  const tapeRolls = Math.max(3, Math.ceil((totalBaskets + totalDanpraLarge + totalDanpraMedium) / 10));
  const airCapRolls = kitchenCbm > 2.0 ? 2 : 1;
  const mattressCovers = Math.max(1, bedCount);
  const workerShoeCovers = Number(environment.workers) || 4;

  return {
    'MAT-BSK-01': totalBaskets,      // 이사 바구니 (청색/대)
    'MAT-BOX-L': totalDanpraLarge,    // 단프라 박스 (대)
    'MAT-BOX-M': totalDanpraMedium,   // 단프라 박스 (중)
    'MAT-HNG-01': hangerBoxes,        // 옷걸이 박스
    'MAT-CVR-BED': mattressCovers,    // 매트리스 커버
    'MAT-FLR-01': 15,                 // 플로링보드 (기본 15장)
    'MAT-TAPE-01': tapeRolls,         // 박스테이프
    'MAT-AIR-01': airCapRolls,        // 에어캡
    'MAT-WRAP-01': 1,                 // 스트레치 필름
    'MAT-SHOE-01': workerShoeCovers,  // 작업용 덧신
  };
}
```

## 6. 팬트리선반 (5단 1자, ㄴ자, ㄷ자) CBM 산정 및 붙박이 기본값 적용 이력

### (1) 팬트리선반 현장 분석 및 결정사항
- **팬트리의 특성**: 아파트 팬트리는 90% 이상이 벽체/천장에 고정 시공된 **붙박이 시스템 가구**이므로, 이사 시 선반 자체를 떼어가지 않고 두고 감.
- **CBM 산정 원칙**: 
  - 선반 프레임 자체의 차량 적재 부피인 **기본 CBM은 `0`으로 설정**.
  - 선반 위에 얹혀진 식료품/주방잡화 수납 짐만 **내품 CBM**으로 산정하여 실제 차량 적재량에 반영.

### (2) 등록된 표준 규격 및 CBM 수치
| 품목명 | 규격 (spec) | 기본 CBM (선반 - 붙박이) | 내품 CBM (수납 짐) | 총 CBM | 비고 |
|---|---|:---:|:---:|:---:|---|
| **팬트리선반** | **5단 1자형** | **0 CBM** | **0.8 CBM** | **0.8 CBM** | 1자 선반 수납 짐 약 8~10박스(바구니) 분량 |
| **팬트리선반** | **5단 ㄴ자형** | **0 CBM** | **1.5 CBM** | **1.5 CBM** | 2면 코너 선반 수납 짐 약 15~18박스(바구니) 분량 |
| **팬트리선반** | **5단 ㄷ자형** | **0 CBM** | **2.5 CBM** | **2.5 CBM** | 3면 워크인 선반 수납 짐 약 25~30박스(바구니) 분량 |

## 7. 향후 시스템 코딩 구현 로드맵
1. **견적서 작성 화면 (`EstimateForm.tsx`)**:
   - `[자재 자동 산출]` 버튼 추가 또는 견적 품목 입력 시 실시간 자재 권장 수량 패널 노출.
   - 산출된 자재 수량을 원클릭으로 견적서 `materials` 필드에 바인딩.
2. **차량 인수인계서 및 PDF 연동 (`LocationInventoryReport.tsx`)**:
   - 산출된 자재 목록을 해당 투입 차량(예: 1호차)의 출고 자재로 자동 연결하여 인수인계서 PDF 생성.
3. **자재 재고관리 (`/inventory`) 출고 연동**:
   - 이사 작업 완료 시 실사용 자재 및 파손/소모 자재 자동 차감 처리.
